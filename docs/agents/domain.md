# Domain Docs

This repository uses a single domain context.

Before engineering work, read:

- the root `CONTEXT.md` for product vocabulary and stage boundaries;
- `docs/development/ARCHITECTURE.md` for module ownership and fact sources;
- `docs/development/ZOL-CATEGORY-COLLECTION.md` for the current source-specific design;
- the authority order in `docs/development/README.md`.

Use the established terms Capture Task, Crawl Plan, Provider, Source Run, Source Request Attempt, Source Snapshot, Source Asset, and Source Dataset. If a proposal conflicts with the authority baseline, report the conflict instead of silently overriding it.
