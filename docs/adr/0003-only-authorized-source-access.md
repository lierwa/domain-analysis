# Provider 只接入有授权的来源入口

本决定保留为历史记录。用户随后明确选择教育研究用途的网页采集路线，京东普通账号网页采集边界由 ADR-0004 取代；品牌官网、监管资料和正式发布物的来源证据要求仍然有效。

所有 Provider 必须先证明当前访问方式和数据用途获得来源授权；公开可见、普通账号可登录或技术上能自动访问都不构成授权。京东当前用户协议限制未经书面许可的第三方工具接入及复制站内和交互数据，因此 MVP 不再把登录京东网页的 Playwright 采集作为交付项；京东只保留官方开放平台 API 或书面许可后的条件式 Provider，品牌官网、说明书和监管来源也必须逐源记录许可依据。

## 后果

- 风控页是停止信号，不通过伪装指纹、验证码绕过、换账号或提高重试继续访问。
- JD Provider 是否进入 MVP，取决于 JOS/京东联盟的申请权限、允许用途和字段覆盖验证；未获权限时如实记录京东时点销售信息未知。
- Crawlee 和 Playwright 只用于来源条款或明确授权允许的网页，不因技术可运行就获得生产准入。
