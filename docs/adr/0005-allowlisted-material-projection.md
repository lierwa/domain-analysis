# 登录态原文通过白名单资料投影进入知识加工

> 2026-08-15：本决定由 ADR-0011 取代。整页 HTML、全页截图和“每来源 projector”不再是持久化或知识加工边界；本文件仅保留为历史记录。

京东登录态采集快照可含配送地区等个性化内容。我们决定把整页 HTML、截图和浏览器会话永久留在本地受限快照区；来源 adapter 只用成熟格式解析器投影允许的商品字段和证据定位，并通过严格 Schema 拒绝未知字段。只有标记为可加工的投影能进入 Codex、清洗和知识包。

## 考虑过的方案

- 拒绝把整页 HTML 直接交给 Codex 并依赖提示词不输出敏感内容；这无法建立数据边界。
- 拒绝把黑名单正则或 PII 检测器作为主门；Microsoft Presidio 很成熟，但官方明确不保证找全敏感信息，中文还需额外 NLP 模型和识别器配置。
- 接受成熟格式解析器的白名单投影＋Zod 严格结构门；HTML 使用 Cheerio，PDF/XLSX 分别使用 R-014 已验证并精确固定的 `unpdf` 与 `read-excel-file`，不引入自研文档解析器或模型服务。

## 结果

每个来源必须维护少量、版本化的允许字段和证据定位；`ProcessableMaterialModule` 按 provider、隐私分区、资源角色和媒体类型选择唯一 projector/resource，并重建系统 provenance。页面或文档格式变化导致必需字段缺失、近似身份或多行命中时失败关闭。Presidio 只在真实漏检证明白名单投影外还需要通用 PII 防线时重新评估，不作为 MVP 生产依赖。
