# ADR-003：知识内容自动判断与人工冲突审核

状态：已接受
日期：2026-09-04

## 简单说明

系统批量处理内容归属、OCR 和图片。可靠结果直接进入知识包，其余内容自动隔离；人只处理会改变最终事实、又不能仅靠机器置信度解决的来源冲突。图片无需人工涂抹水印，OCR 也无需逐行勾选。

## 背景

一次完整采集批次可能包含数千张图片和更多 OCR 行。逐图修补、逐行勾选会让工作量随原料数量线性增长，不能形成可重复生产的产线。正式微波炉样本也证明，模型能发现 OCR 错字，但单看候选置信度仍可能把站点水印当作正文；因此自动阶段必须同时使用原图、OCR 文字、置信度、坐标和内容归属，并把不可靠结果隔离。

同一字段来自多个有效来源但值不一致时，差异可能来自版本、适用条件或来源语境。这类决定会改变成品事实，需要负责人按整组证据取舍。

## 决定

1. 来源明确且通过结构校验的字段由确定性规则自动准入；加工失败和空内容进入加工异常队列。
2. 非结构化内容、OCR 和图片进入同一个自动判断阶段。问题按最多 32 个问题、16 份原件有界分组，所有分组累计写入同一审核记录。
3. 自动判断复用现有 Codex App Server ephemeral turn、Zod output schema、只读 sandbox 和关闭 web search 的配置。输入只包含当前候选、来源定位、OCR 置信度/四边形和必要图片；结构化输出中的外部 `null` 只在协议边界归一化，校验失败最多按同一错误完整纠正一次。
4. OCR 与非结构化内容只有在模型给出高置信采用、且候选属于当前问题范围时进入准入；未采用、低置信、越界和证据不足的候选自动隔离。
5. 图片只有三种首轮自动动作：生成标准 PNG 副本、按 OCR 四边形生成遮罩并用 OpenCV Telea 修补、整图隔离。遮罩面积不得超过原图 10%，输出必须保持遮罩外像素不变；生成的副本再由视觉模型对照原图验收，出现修补痕迹、内容损失或水印残留时自动隔离。
6. 自动结果必须同时匹配加工代次、审核修订和问题指纹。任一身份变化后旧结果失效；版本输入摘要还绑定自动建议、人工决定和图片副本哈希，内容改变后必须形成新版本。
7. 同字段来源冲突进入人工整组审核。历史运行中的手工图片副本和决定只读保留；新运行不再产生逐行 OCR、手工图片处理或人工图片验收任务。
8. 审核界面使用页面单一滚动：顶部显示四类数量，左侧显示整组问题，右侧只显示完成决定所需的证据和动作。自动问题展示汇总结果，不展开逐行选择或处理参数。

## 后果

- 正常运行的人工工作量由原料数量转为少量来源冲突数量，数千张图片不会自动生成数千次人工确认。
- 自动阶段不能证明可靠的内容保持隔离，不阻塞其他合格内容、图片或已发布版本。
- Source Dataset 原件保持不可变；Knowledge Processing 保存自动建议、处理副本、遮罩来源、视觉验收、准入投影和人工冲突决定。
