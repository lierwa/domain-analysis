# Domain Docs

This repository uses a single domain context.

Before engineering work, read:

- the root `CONTEXT.md` for the project vocabulary;
- relevant decisions under `docs/adr/`;
- the authority order in `docs/development/README.md`.

Use the established terms Capture Task Interview, Interview Working Record, Capture Task Draft, Capture Task, Crawl Plan, Provider, Source Run, Source Snapshot, Source Asset, and Source Dataset. If a proposal conflicts with an accepted ADR, report the conflict instead of silently overriding it.
