# 数据抓取平台路线图

状态：进入 ZOL 单来源开发验证
更新日期：2026-08-28

## 当前目标

在阶段 1 建立并验证一条 ZOL 门类到品牌、型号和参数配置的持久抓取链。当前不进入数据清洗。

## Z0 技术设计

产物：领域上下文、架构边界、ZOL 技术设计、调研登记和开发交接。

通过门：页面入口、品牌优先级、单品牌抓取、双品牌调度、控频和停止规则全部有明确事实源与验证方式。

状态：完成。

## Z1 单品牌纵向验证

产物：最小 ZOL adapter 接线和 V0 Source Dataset。

通过门：

- 7 页面验证按计划完成；
- 品牌入口、P1、分页、型号 ID 和参数区块可识别；
- 请求与原始页面持久化并可查看；
- 没有访问限制和遗留运行状态。

停止门：V0 失败时只定位当前链路，不进入并行开发。

## Z2 双品牌调度验证

产物：两个 P1 品牌交错调度的 V1 Source Dataset。

通过门：

- 两个品牌共享一个 ZOL origin gate；
- 每分钟最多 2 次、最小间隔 30 秒；
- 队列和数据库状态可恢复；
- 两个品牌分别对账完成与缺口。

停止门：出现访问限制或共享 gate 失效时停止，不进入放量验证。

## Z3 放量与 P1 批次

先用最多 10 个页面验证每分钟 4 次、最大网络并发 2。验证通过后，才能生成并确认 P1 品牌批次 Crawl Plan。

阶段产物是 P1 品牌当前型号及参数的不可变 Source Dataset。停产型号和 P2/P3 品牌作为后续增量计划。

## 阶段 2

数据清洗只在阶段 1 原始数据完成验收后另行设计。
